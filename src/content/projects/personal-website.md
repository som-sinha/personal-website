The site you're looking at. It's a fully static Astro site: every page is
built ahead of time from content files in the repo, so there's no server or
database behind it. Pushing to GitHub rebuilds and deploys it on Cloudflare.

The code is [open on GitHub](https://github.com/som-sinha/personal-website)
if you want to poke around.
